There is an interesting [4d/2d correspondence](https://arxiv.org/abs/1408.6522) that has been studied over the past few years. One such correspondence is the Schur index of the 4d theory matches the character of the algebra.

$$\mathcal I_{\chi}(q;\mathbf{x}) = \mathcal I^{\text{Schur}}(q;\mathbf{x}) = \operatorname{Tr}_{\mathcal H}(-1)^Fq^{L_0}. $$

Essentially, given a 4d \\(\mathcal N = 2 \\) SCFT, we can find a chiral algebra corresponding to a protected subsector of the 4d theory


$$ \text{4d theory} \to \text{2d VOA}.$$

Given either a 4d or 2d theory, we can compute the Schur index (easily if the theory is Lagrangian, less so if it is non Lagrangian)/character of the VOA. We can also compute the character of a new theory obtained by gauging the original theory (or Drinfeld-Sokolov reduction).

Recently Grant has been talking to us about gauging a particular VOA which somehow gives us a new VOA matching a particular non-Lagrangian theory, [Argyres-Wittig](https://arxiv.org/abs/1412.8129) (C2U1). We[^1] have managed to compute the Schur index of the theory exactly in terms of elliptic functions and have matched not only the non-flavored index, but the flavored index *and central charge* \\(c_{4d} = 19/12\\).

The path is the following:
![diagram](/posts/scft/img/cd.PNG)

We start with the \\((A_1,D_4) \\) theory and add 5 half hypers in the fundamental of \\(\mathrm{SU}(2)\\). There are an odd number of fermions so we have a Witten anomaly and can't gauge it. 

However, we *can* go down to the 2d theory and gauge that as the 5 half hypers have turned into our 5 ghosts. We can compute the index of the resulting VOA which turns out to match the index of the C2U1 theory. 

Wait, *so what the \*\*\*\* happened in 4d??!!* 

We shouldn't have been able to gauge it and get a new theory. On the 2d side, I can Drinfeld-Sokolov whatever the hell I want but usually the resulting VOA doesn't correspond to any 4d theory. In this case, for some reason it matches with C2U1. 

In principle, this could be an incredible coincidence. It is expected that a VOA should correspond to a particular theory in 4d, but not necessarily proven. It would be an insane coincidence if we matched the unflavored index *and* the flavored index *and* the central charge of C2U1 without the 4d theory actually being C2U1.

Despite this, I still could not have gauged the original 4d theory. 

The original Argyres-Douglass theory is fine, so it can't be that adding the half-hypers fixed the theory.

We asked Jacques and he put forth the only idea that makes sense. There are two problems that need to be solved:

1) How did we gauge when in 4d the theory was anomalous?
2) C2U1 does not have a conformal manifold (it is stuck at a point), but gauging a 4d theory usually enlarges the CM.

To solve both of these problems, one solution is a mechanism similar to what happens for \\(\mathcal N = 3\\) theories. \\(\mathcal N = 3\\) theories are stuck at strong coupling and thus, no Lagrangian description exists[^2]. There must be a (non-anomalous) theory stuck in the UV which has an obstruction to flowing down to the original Argyres-Douglass theory with 5 half hypers. This would allow us to gauge it, and also explain why the conformal manifold after gauging might just go to a point. 

It's an elegant solution that kills 2 birds with one stone and the only one I can imagine working. One *may* solve the first problem by assuming the original theory may be relative[^3] and gauging somehow makes the 5d anomaly theory trivial, but this doesn't solve the the 2nd problem (nor do I know the state of cancelling Witten anomalies with gapped TQFTs[^4]).

Anyways, it looks like I'll be learning about \\(\mathcal N = 3\\) theories which is not the least interesting thing to learn about.









[^1]: Mainly Ainesh.

[^2]: If you try to write on down, you will find that the supersymmetry is really \\(N=4\\).

[^3]: As 6d theories and many class S theories are.

[^4]: Tachikawa has showed that Green-Schwarz cannot cure Witten-type anomalies.
